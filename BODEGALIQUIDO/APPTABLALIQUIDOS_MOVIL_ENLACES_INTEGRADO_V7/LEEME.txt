PROVSOFT - APPTABLALIQUIDOS MOVIL ENLACES V4

OBJETIVO
Aplicación independiente, mobile-first, para caminar en piso y enlazar conceptos de facturas autorizadas con el catálogo interno.

CAMBIOS V4
- Catálogo de productos activos se descarga al iniciar y se guarda en IndexedDB.
- La aplicación permanece bloqueada hasta que el catálogo activo esté listo.
- Sugerencia inicial por descripción del concepto de factura.
- Búsqueda manual libre por descripción, código, marca o departamento.
- Cámara como opción adicional para leer código de barras.
- Tarjetas de factura con porcentaje de artículos enlazados.
- Los enlaces existentes se pueden abrir y EDITAR.
- Modal/editor de equivalencia con:
  * descripción/llave de factura
  * código de factura
  * unidad de factura
  * producto interno
  * unidad de inventario
  * cantidad de factura
  * factor / piezas por caja
  * cantidad final que entra
- El producto interno puede cambiarse incluso si el concepto ya estaba enlazado.
- El factor y la cantidad final se recalculan mutuamente.
- Las equivalencias continúan guardándose en:
  almacenes/Almacen_Liquidos/configuracion/equivalencias_factura/items
- Las entradas continúan guardándose en:
  almacenes/Almacen_Liquidos/entradas
- Recuperación de equivalencias prioriza descripción normalizada exacta, conserva compatibilidad con enlaces anteriores por código o texto legado.
- Si se cambia la llave de una equivalencia, se elimina el documento anterior para evitar duplicados activos.

PC
Ejecutar INICIAR_PC.bat.

CELULAR / CAMARA
Para cámara se recomienda servir la aplicación por HTTPS (por ejemplo Firebase Hosting).

ACTUALIZACIÓN AUTOMÁTICA DEL CATÁLOGO
- La descarga completa de productos activos se realiza automáticamente una sola vez por día.
- Las siguientes aperturas del mismo día usan IndexedDB y no vuelven a descargar todo el catálogo.
- No existe actualización manual del catálogo.
- Si se escribe o escanea un código que no está en IndexedDB, la app lo busca automáticamente en Firebase.
- Si el producto existe y activo=true, se agrega inmediatamente a IndexedDB y queda disponible el resto del día.
- Al día siguiente se vuelve a descargar la foto completa de productos activos, eliminando localmente los productos que hayan sido desactivados.

V7 AUTOMATICA
- Sugerencias por descripcion se muestran automaticamente al abrir el concepto.
- Eliminados botones Sugerir y Buscar codigo de factura.
- Busqueda manual siempre disponible escribiendo descripcion o codigo.
- Camara disponible como alternativa.
- Datos originales de factura no editables.
- Conversion: Cantidad factura, Piezas por caja, Cantidad que entra.
